# PBT slice implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add five Hypothesis structural properties proving no birth moment yields a broken chart.

**Architecture:** One new test file `tests/test_properties.py` with a shared birth-input strategy; Hypothesis is a test-only extra, never imported by `src/dashaflow`. Each property runs ~25 examples with wall-clock deadlines disabled; production code changes only if a property exposes a real engine bug.

**Tech Stack:** Python 3.10+, Hypothesis 6+, pytest, ruff.

**Spec:** `docs/superpowers/specs/2026-11-08-pbt-slice-design.md`

## Global Constraints

- Hypothesis is a test-only dependency (`test` and `dev` extras); `src/dashaflow` must never import it.
- Strategies: dates 1900-01-01..2100-12-31, latitudes -66..66, longitudes -180..180, timezones from a fixed list (Asia/Kolkata, UTC, America/New_York, Pacific/Auckland, Arctic/Longyearbyen); variants sampled from all eight canonical keys plus aliases.
- Every property uses `@settings(max_examples=25, deadline=None)`; the slice must add under ~1 min to the local suite.
- Full gate stays `python -m pytest tests/` (parse `testsuite` counts from JXML) and `python -m ruff check src tests`; new `zip()` calls need `strict=False`/`strict=True` (B905).
- A failing property is resolved by an engine fix (+ regression test) or a property fix, recorded in the commit message; deletion is never a resolution.
- Existing positional call order and Lahiri default unchanged; SAV=337 invariant intact.

## Review Focus

- Polar latitudes (|lat| > 66.5, e.g. Longyearbyen 78.2N): the houses fallback is silent on this backend — a cast there must still yield `ashtakavarga.total_bindus == 337` and finite lagna. Pinned in Task 1 as a fixed-example test.
- Far-boundary dates (1900-01-01, 2100-12-31): Moshier-only range edges must keep dasha timelines contiguous. Pinned in Task 3 as fixed examples.
- Leap-day birthdays (Feb 29): the date strategy must generate valid leap dates without skew. Pinned in Task 1 (`st.dates()` covers this; one explicit Feb-29 example test).
- DST-fold local times (America/New_York 2024-11-03 01:30 occurs twice): ambiguous times must cast without error and deterministically. Pinned in Task 4 as a fixed-example test.
- Variant aliases (`kp`, `kp_new`, `LAHIRI`, `lahiri-icrc`): sampled aliases must behave identically to their canonical keys. Pinned in Task 2 (alias sampling in the strategy + equality assertion).

```python
import datetime

import pytest
from hypothesis import given, settings, strategies as st

import dashaflow
from dashaflow._ayanamsha import AYANAMSHA_VARIANTS

VARIANTS = list(AYANAMSHA_VARIANTS) + ["kp", "kp_new", "LAHIRI", "lahiri-icrc"]

TIMEZONES = ["Asia/Kolkata", "UTC", "America/New_York",
             "Pacific/Auckland", "Arctic/Longyearbyen"]


@st.composite
def birth_input(draw):
    date = draw(st.dates(min_value=datetime.date(1900, 1, 1),
                         max_value=datetime.date(2100, 12, 31)))
    return (
        date.isoformat(),
        f"{draw(st.integers(0, 23)):02d}:{draw(st.integers(0, 59)):02d}",
        draw(st.floats(min_value=-66.0, max_value=66.0,
                       allow_nan=False, allow_infinity=False)),
        draw(st.floats(min_value=-180.0, max_value=180.0,
                       allow_nan=False, allow_infinity=False)),
        draw(st.sampled_from(TIMEZONES)),
    )


@settings(max_examples=25, deadline=None)
@given(birth_input(), st.sampled_from(VARIANTS))
def test_sav_totals_337(birth, variant):
    chart = dashaflow.cast_chart(*birth, ayanamsha=variant)
    assert chart["ashtakavarga"]["total_bindus"] == 337


def test_polar_chart_keeps_sav():
    chart = dashaflow.cast_chart("1990-06-15", "12:00", 78.2232, 15.6469,
                                 "Arctic/Longyearbyen")
    assert chart["ashtakavarga"]["total_bindus"] == 337


def test_leap_day_casts():
    chart = dashaflow.cast_chart("2000-02-29", "06:15", 28.6139, 77.2090,
                                 "Asia/Kolkata")
    assert chart["ashtakavarga"]["total_bindus"] == 337
```

```python
from dashaflow.constants import ZODIAC_SIGNS


def _absolute(planet):
    return ZODIAC_SIGNS.index(planet["sign"]) * 30 + planet["degree_precise"]


@settings(max_examples=25, deadline=None)
@given(birth_input(), st.sampled_from(VARIANTS))
def test_variant_shift_matches_ayanamsha_difference(birth, variant):
    lahiri = dashaflow.cast_chart(*birth)
    other = dashaflow.cast_chart(*birth, ayanamsha=variant)
    expected = (other["metadata"]["ayanamsha_degrees"]
                - lahiri["metadata"]["ayanamsha_degrees"]) % 360
    for name in ("Sun", "Moon", "Mars", "Mercury", "Jupiter", "Venus", "Saturn"):
        delta = (_absolute(other["planets"][name])
                 - _absolute(lahiri["planets"][name])) % 360
        assert abs(delta - expected) < 0.001, (birth, variant, name)
```
